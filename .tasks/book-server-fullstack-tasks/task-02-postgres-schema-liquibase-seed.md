# Task 02: PostgreSQL Schema + Liquibase XML + Seed

**Type:** Code Modification
**Suggested agent:** Code

## Goal
Спроектировать PostgreSQL-схему для библиотеки книг, реализовать её через Liquibase XML changelogs и залить seed-данные жанров.

## Why This Task Exists
Бизнес-логика приложения целиком стоит на схеме БД. В `sql/` есть исторические MySQL-дампы — это **референс**, но не готовая схема. PG-схема должна:
- быть оптимизирована под PG (BIGSERIAL, BOOLEAN, BYTEA, timestamp triggers);
- иметь полнотекстовый поиск (отсутствующий в исходных дампах);
- содержать дополнительные сущности (users, book_lists, share_tokens, import_jobs, conversion_jobs), которых в исходных дампах нет;
- поддерживать inpx-импорт (archive_name, inpx_source, offset).

Liquibase XML — выбранный пользователем инструмент управления миграциями.

## Spec Coverage
- Requirements: R2, R3

## Required Inputs

- Ключевые исходные таблицы и сущности (из research):
  - книги (`libbook`), авторы/переводчики в одной таблице (`libavtorname`), серии (`libseqname`), жанры (`libgenrelist` — 272 жанра), M:N-связи (`libavtor`, `libtranslator`, `libseq`, `libgenre`), аннотации (`libbannotations`/`libaannotations`).

  - `sql/lib.libgenretranslate.sql` — маппинг устаревших кодов (опционально).

## Files/Areas

- `backend/src/main/resources/db/changelog/changes/001-core-domain.xml` — основные сущности: `genres`, `persons`, `series`, `books`, `book_authors`, `book_translators`, `book_genres`, `book_series_members`, `book_files`, `annotations`.
- `backend/src/main/resources/db/changelog/changes/002-fts.xml` — tsvector-колонки на `books` и `persons`, GIN-индексы, функции и триггеры для автоматического обновления.
- `backend/src/main/resources/db/changelog/changes/003-users-auth.xml` — `users`, `roles`, `user_roles`.
- `backend/src/main/resources/db/changelog/changes/004-book-lists.xml` — `book_lists`, `book_list_items`, `book_list_shares` (с уникальным share_token).

- `backend/src/main/resources/db/changelog/changes/006-seed-genres.xml` — seed жанров (changeset вставляет ~272 записи через `<loadData>` или `<sql>`).
- `backend/src/main/resources/db/changelog/seed/genres.csv` — выгрузка жанров из `lib.libgenrelist.sql` в CSV (для `<loadData>`).

## Constraints / Non-Goals
- Не загружать книги/авторов/серии из MySQL-дампов — только seed жанров.
- Не использовать `spring.jpa.hibernate.ddl-auto` для DDL — только Liquibase.
- Не привязываться к именам и типам MySQL — использовать PG-нативные типы:
  - PK = `BIGSERIAL` / `bigint generated by default as identity`.
  - boolean вместо `tinyint(1)`/`char(1)`.
  - `timestamp with time zone` для всех временных полей.
  - md5 — `varchar(32)` (HEX) для совместимости с inpx.
- В каждом changeset обязательно `id` и `author`. Использовать `<rollback>` где это разумно.
- Имена столбцов и таблиц — `snake_case`.
